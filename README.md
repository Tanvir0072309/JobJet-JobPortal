# 🚀 JobJet - Full-Stack Job Portal Application

JobJet is a modern, full-stack job portal platform built with **Node.js, Express, PostgreSQL, and Expo React Native**. It features real-time job listings, user authentication, profile management, and seamless application tracking.

## ✨ Features

- **User Authentication:** Secure JWT-based Login and Registration.
- **Job Listings:** Explore, search, and filter job postings in real-time.
- **Employer Portal:** Create and manage job posts effortlessly.
- **Responsive & Dynamic:** Powered by dynamic API routing for cloud production.

---

## 🛠️ Tech Stack

### **Backend**
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** PostgreSQL (Hosted on Neon.tech)
- **Authentication:** JSON Web Tokens (JWT) & Bcrypt
- **Deployment:** Render (`https://jobjet-jobportal.onrender.com`)

### **Frontend / Mobile App**
- **Framework:** Expo (React Native)
- **Language:** JavaScript / TypeScript
- **Environment Management:** `react-native-dotenv` / `EXPO_PUBLIC_API_URL`
- **Build System:** Expo Application Services (EAS Build)
